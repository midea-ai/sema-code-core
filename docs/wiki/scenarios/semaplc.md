# SemaPLC

## 项目概述

**SemaPLC** 是一个 sema-core Agent 驱动的工业 PLC 编程 IDE：用自然语言描述控制任务，Agent 端到端地生成、编译、部署并验证 PLC 程序，并以梯形图、实时变量和过程仿真呈现结果。

完整项目地址：[SemaPLC](https://github.com/midea-ai/SemaPLC)（[中文 README](https://github.com/midea-ai/SemaPLC/blob/main/README.zh-CN.md)）
